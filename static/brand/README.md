## 二、文件清单与用途

| 文件 | 规格 | 适用场景 | 规范要求 |
| :--- | :--- | :--- | :--- |
| `favicon.svg` | 48×48 | 浏览器 Favicon、Web 侧栏产品标 | 48×48 绿砖，圆角 12px，stroke 1.7 航道 glyph |
| `鹿溪志愿-产品标识.svg` | 48×48 | 资产中文归档副本 | 与 `favicon.svg` 同步 |
| `logo.svg` | 360×56 | 横版字锁（产品方标 + 标准排印） | 适用于营销页、文档头、欢迎面板 |
| `鹿溪志愿-横版字锁.svg` | 360×56 | 资产中文归档副本 | 与 `logo.svg` 同步 |
| `luxi-lab.svg` | 48×48 | 实验室出品方标识（浅底） | 无方框，Y 杆鹿溪绿 + 进化蓝横线 |
| `luxi-lab-inverse.svg`| 48×48 | 实验室出品方标识（深底/反白） | 无方框，Y 杆反白 + 进化蓝横线 |
| `luxi-lab-main.svg` | 矢量 | 官方写实主标（对外正式文件专用）| **禁止在产品 UI / 关于 / 页脚中作为图像引用** |

## 三、界面排版铁律（P0 自检）

1. **双标等大**：在产品关于页（About）、页脚或说明文档双标位中，产品方标与实验室符号标**必须并排等大**（统一为 48×48 或 64×64），禁止一大一小，禁止上下失衡。
2. **写实标绝不进 UI**：侧边栏出品标必须使用 `luxi-lab-inverse.svg`（或 `luxi-lab.svg`），禁止渲染写实主标。
3. **符号标不加框**：实验室符号标依赖底色对比成立，不得为其添加绿砖背景套框。
